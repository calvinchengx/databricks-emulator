# v0.2.3

**UC OSS decimal columns.** v0.2.2 registered DESCRIBE `decimal(p,s)` as
JSON `"type":"decimal"`. Unity Catalog OSS 400s that (`Unsupported Delta
primitive type: decimal`). The warehouse shim now writes
`"type":"decimal(p,s)"` (and `decimal(10,0)` when the engine omitted
precision).

```
docker pull ghcr.io/calvinchengx/databricks-emulator:0.2.3
```

Pull `0.2.3` if gold models include decimal columns (Contoso `fct_orders`
does). Nothing else changed from v0.2.2.
