# v0.2.4

Two follow-ups on the v0.2.2 warehouse shim, both required for Contoso gold
beyond `dim_*` and a first `dbt run`.

```
docker pull ghcr.io/calvinchengx/databricks-emulator:0.2.4
```

## Decimal columns

Sail's unity catalog provider rejects three-part reads of
`decimal(p,s)` (`Unsupported complex type`). EXTERNAL registration now
advertises `DOUBLE` for DESCRIBE decimals. The Delta files still hold the
engine type.

## CREATE OR REPLACE

v0.2.2 sent Sail `CREATE TABLE IF NOT EXISTS` so leftover files from a
previous run made dbt fail. `CREATE OR REPLACE TABLE cat.sch.t` now reaches
Sail as unqualified `CREATE OR REPLACE TABLE \`t\` … LOCATION`. UC register
still treats already-exists as success.

Pull `0.2.4` for gold models that join decimal facts, or for a second
`dbt run` on the same volume.
